# Discord Forum Collector — v1

Архивная версия приложения до изменений GUI v2. Запуск:

```bash
python discord_forum_gui.py
```

Сбор выполняется через залогиненный веб-интерфейс Discord. Скрытая информация недоступна; имена/роли голосовавших собираются только если они видны пользователю в Discord.
