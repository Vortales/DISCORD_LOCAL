# Discord Forum Collector — v2

Запуск графического интерфейса:

```bash
python discord_forum_gui.py
```

В полях GUI доступны `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+A`, а также контекстное меню по правой кнопке мыши. Настройки формы автоматически сохраняются в `.discord_forum_gui_settings.json` в этой папке, поэтому значения и флажки восстанавливаются при следующем запуске. Профиль Chromium и экспорт также сохраняются отдельно от других версий.

Сбор работает через залогиненный веб-интерфейс Discord. Скрытая информация недоступна; имена/роли голосовавших собираются только если они видны пользователю в Discord.
