# Discord Forum Collector

Сбор данных форума Discord через залогиненный веб-интерфейс Chromium — без бота и bot token. Имена, ID и роли голосовавших сохраняются только когда Discord показывает их в интерфейсе текущему аккаунту; скрытые данные не извлекаются.

## Версии

Каждая версия находится в отдельной папке в корне репозитория:

- `v1/` — предыдущая версия.
- `v2/` — GUI с копированием/вставкой и запоминанием полей и флажков.
- `v3/` — текущая версия: остаётся в одной вкладке, открывает следующие публикации кликом по карточке списка, обрабатывает их последовательно и дожидается появления строк голосовавших. Опросы в сообщениях публикации обрабатываются по отдельности.

Запуск актуальной версии из корня:

```bash
python discord_forum_gui.py
```

Или напрямую:

```bash
python v3/discord_forum_gui.py
```

Настройки, профиль Chromium и экспорт каждой версии изолированы в соответствующей папке. В интерфейсе v3 работают `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+A` и контекстное меню по правой кнопке мыши.

Для запуска сборщика напрямую:

```bash
python v3/discord_forum_collect.py [GUILD_ID] [FORUM_CHANNEL_ID]
```

По умолчанию используются сервер `1514607659758653560` и форум-канал `1515423283606982776`. Для точечного теста используйте `--post-id POST_ID`; чтобы остановить последовательный сбор после публикации включительно — `--stop-after-post-id POST_ID`.
