# Discord Forum Collector

Сбор данных форума Discord через залогиненный веб-интерфейс Chromium — без бота и bot token. Имена, ID и роли голосовавших сохраняются только когда Discord показывает их в интерфейсе текущему аккаунту; скрытые данные не извлекаются.

## Версии

Каждая версия находится в отдельной папке в корне репозитория:

- `v1/` — предыдущая версия.
- `v2/` — GUI с копированием/вставкой и запоминанием полей и флажков.
- `v3/` — одна вкладка, переход между публикациями кликом по карточкам форума и последовательный сбор.
- `v4/` — текущая версия: сохраняет имена для всех видимых вариантов голосования, безопасно переживает пустые/посторонние `View Poll` окна и продолжает сохранять публикацию даже при ошибке диагностики.

Запуск актуальной версии:

```bash
python discord_forum_gui.py
```

Или напрямую:

```bash
python v4/discord_forum_gui.py
```

Параметры, профиль Chromium и экспорт каждой версии изолированы в её папке. В v4 каждый вариант с ненулевым счётчиком записывается отдельно: уже выбранный берётся из открытого списка, прочие варианты нажимаются и собираются по видимым строкам. Ожидаемый счётчик сравнивается с числом собранных строк; пустой/не готовый список явно отражается в диагностике.

Для запуска сборщика напрямую:

```bash
python v4/discord_forum_collect.py [GUILD_ID] [FORUM_CHANNEL_ID]
```

По умолчанию используются сервер `1514607659758653560` и форум-канал `1515423283606982776`. Для точечного теста используйте `--post-id POST_ID`; чтобы остановить последовательный сбор после публикации включительно — `--stop-after-post-id POST_ID`.
