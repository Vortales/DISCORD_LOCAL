# Discord Forum Collector — v3

Запуск графического интерфейса из корня репозитория:

```bash
python v3/discord_forum_gui.py
```

v3 сохраняет одну вкладку браузера открытой на протяжении сбора и переключает темы кликами по карточкам форума вместо повторного `goto` для каждой публикации. Сбор идёт последовательно, чтобы не создавать несколько конкурирующих вкладок и не терять контекст списка.

В каждой публикации прокручивается только область чата/темы; каждое сообщение с опросом проверяется отдельно. После переключения варианта сборщик ждёт видимые строки, собирает их с прокруткой списка и сохраняет ожидаемое число голосов, число строк и результат сверки. Если после ожидания строки всё ещё не распознаны, диагностика содержит сведения о выбранной вкладке и обнаруженной области списка.

В GUI доступны `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+A` и контекстное меню правой кнопкой. Настройки, профиль браузера и экспорт хранятся отдельно в папке v3. Скрытые Discord данные недоступны.
